# Raízes Urbanas

Página web estática desenvolvida como atividade acadêmica de HTML5, CSS3 e JavaScript.

O projeto apresenta uma página responsiva sobre hortas comunitárias urbanas, com estrutura semântica, navegação interna, imagem com texto alternativo, formulário acessível, estilos criados com Flexbox, Grid e media queries, além de um menu dropdown de personalização em JavaScript para manipulação do DOM, alteração visual da página e validação de formulário.

## Arquivos

- `index.html`: estrutura da página.
- `styles.css`: estilos, layout e responsividade.
- `script.js`: interatividade, alteração de conteúdo/estilos e validação de formulário.
- `assets/horta-comunitaria.png`: imagem principal da página.
- `relatorio.md`: relatório de desenvolvimento do projeto.
