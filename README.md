# Raízes Urbanas

Página web estática desenvolvida como atividade acadêmica de HTML5 e CSS3.

O projeto apresenta uma página responsiva sobre hortas comunitárias urbanas, com estrutura semântica, navegação interna, imagem com texto alternativo, formulário acessível e estilos criados com Flexbox, Grid e media queries.

## Arquivos

- `index.html`: estrutura da página.
- `styles.css`: estilos, layout e responsividade.
- `assets/horta-comunitaria.png`: imagem principal da página.
- `relatorio.md`: relatório de desenvolvimento do projeto.
